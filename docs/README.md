# 3DVQL Project Page v4

Academic project page styled after AAD-1, with an AnimalTrack-style animated visualization wall.

The wall uses 36 compressed animated WebP previews sampled from the local 3DVQL visualization set so the page remains practical for GitHub Pages deployment.

Preview:

```bash
python -m http.server 8000
```

Published at https://wuhengliangliang.github.io/3DVQL/.

GitHub Pages uses the `main` branch and the `/docs` folder. Push changes to this
folder to update the website. Keep `.nojekyll` so assets are served directly.
